# 2026-08-13 — 旅行 AI 规划助手

## 完成

- 新增旅行功能第二层的第一版「AI 帮我规划」。
- 旅行档案表单新增预算、旅行节奏、偏好和必去／不想去地点输入。
- 使用已配置的 DeepSeek 服务端密钥生成可编辑旅行初稿，包括建议住宿区域与市内交通、逐日景点／街区／活动安排，以及出行前核验提醒。
- AI 初稿先在表单内预览；用户点击「填充到表单」后仅补充当前空字段，不覆盖已有手动内容。
- 不将开放时间、票价、班次或预订状态作为事实输出，统一提醒用户在出行前自行核验。
- 新增 Vercel Serverless Function `api/plan-travel.js`，密钥不暴露至浏览器。

## 验证

- `node --check api/plan-travel.js` → 通过
- `npx tsc --noEmit` → 通过
- `npx vite build` → 通过（仅有既有主包体积提示）
